# IRA SOUL Corporate Website

A responsive, static corporate website for IRA SOUL, covering Accounting & Financial Services and Offline Advertising & Marketing.

## Deploy on Cloudflare Pages

1. In Cloudflare, open **Workers & Pages → Create → Pages → Connect to Git**.
2. Select `suraj1862323/ira-soul-corporate` and the `main` branch.
3. Framework preset: **None**.
4. Build command: leave blank. Build output directory: `/` (root).
5. Deploy. Add `irasoul.in` and `www.irasoul.in` under the Pages project's Custom Domains and follow Cloudflare's DNS instructions.

## Before publishing

- Replace `hello@irasoul.in` in `index.html` with the confirmed business email/contact.
- Add a verified WhatsApp number if a WhatsApp enquiry button is required.
- Confirm permission to display each client name/logo. The current client list is text-only; no logos or endorsements are implied.
- Confirm the exact scope and authorisations for statutory filing or regulated professional services.

No backend or customer data collection is configured. The enquiry CTA opens the visitor's email application.
